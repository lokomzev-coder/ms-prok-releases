# MS-PROK: установщики и обновления

Здесь лежат только готовые установщики MS-PROK для Windows и файлы автообновления. Исходного кода нет.

## Как установить

1. Откройте раздел **Releases** справа и скачайте `MS-PROK-Setup-….exe` из последнего выпуска.
2. Запустите файл. Если Windows покажет «Неизвестный издатель»: **Подробнее → Выполнить в любом случае** (один раз, приложение пока без цифровой подписи).
3. Программа установится сама (права администратора не нужны), на рабочем столе появится ярлык «MS-PROK». Войдите логином и паролем МойСклад.

Дальше программа обновляется сама: когда выходит новая версия, внизу справа появляется плашка «Доступна версия» с кнопкой «Перезапустить и обновить».
